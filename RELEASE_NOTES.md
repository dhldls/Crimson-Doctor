# Crimson Doctor v2.0.3 Release Notes

Crimson Doctor is a Windows freeware tool for Crimson Desert crashes, launch issues, saves, and modding support.

## Highlights

- Passive crash-log support is now the main crash answer path.
- Game Crashed opens Reports > Crashes for real cdr-crash-*.json logs.
- The package ships CrimsonDoctor.exe and Crash Probe\CDrCrashProbe.asi together.
- Verify Crash Probe checks ASI install state and crash-log evidence.
- External Launch Watch is the manual external launch/process-health audit path.
- Settings autosave on change, and Your IQ saves as the default Doctor Read tone.
