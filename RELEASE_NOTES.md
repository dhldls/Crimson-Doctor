Crimson Doctor is a local Windows freeware tool for Crimson Desert troubleshooting, diagnostics, and modding support.



## What's New

Startup now uses the opening splash as a real boot pass for local startup checks instead of the old cosmetic placeholder splash screen.

Doctor Read startup report now explains useful boot findings in the selected readability mode.

Default Doctor Read readability is now Mid for clearer first-run text.

Completed actions now lead with what happened, why it matters, and what to try next.

ADDED Vague issue searches such as bug reports or "tool not work" now route toward support receipts.

Support receipts now ask for better repro details: clicked route, input mod/package, Doctor output/report, mod manager, game version, last working version, and visible error text.

Added read-only awareness for pycrimson and CrimsonDesertTools-style visible artifacts where public source evidence supports it.
