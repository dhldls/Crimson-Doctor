# Crimson Doctor v1.0.2 RC Release Notes

Crimson Doctor v1.0.2 is the first public Crimson Doctor release line and the major continuation of CD JSON Mod Auto Patcher.

## Download

Download `CrimsonDoctor-1.0.2-windows-standalone.zip` from GitHub Releases or the official Nexus Mods page.

Extract the ZIP and run `CrimsonDoctor.exe`.

## Highlights

- Integrated CD JSON Mod Auto Patcher engine.
- JSON mod validation, patching, dry-run scan, backup inventory, and compatibility reports.
- Launch Watch for FTS, startup crash, CTD, launcher handoff, abnormal exit, timeout, interruption, or clean exit.
- Crash explanation and readable Doctor Verdict output.
- Doctor Navigator guided issue/goal workflows.
- Save timelines, restore planning, restore transactions, rollback records, and cloud-risk checks.
- Toolchain audit, mod-output audit, external manager report intake, conflict evidence, native plugin audit, and archive proof planning.
- Logs page for previewing, copying, opening, and revealing recent Doctor reports.
- Doctor Read with readability modes and expanded wording variation.

## Safety Boundaries

Crimson Doctor does not replace your mod manager, inject into the game, patch memory, silently rewrite manager configs, upload telemetry, or claim universal save repair.

Unsupported formats are reported as unknown instead of guessed.
